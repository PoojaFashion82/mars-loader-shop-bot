# Telegram Demo Bot

## Features
- 👋 Welcome Message
- 📢 Official Channel Button
- 📋 Menu Button
- 💬 Support Button
- 🔒 MARS_LOADER_KEY
- 🔒 ZTRAX_LOADER_KEY
- 🔒 FIRE.X_LOADER_KEY
- 💰 Price Menu
- 💳 UPI Payment Link
- 🚀 Free Deploy on Render

## Files
- main.py
- requirements.txt
- render.yaml
- README.md

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Deploy
Upload this project to GitHub and connect it with Render.
